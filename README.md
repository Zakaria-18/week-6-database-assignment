## Assignment Overview

This assignment focuses on understanding and implementing SQL joins to retrieve related information from multiple database tables using the MySQL Classic Models database.

## Learning Objectives

1. Understand and implement INNER JOIN, LEFT JOIN, and RIGHT JOIN.
2. Retrieve information from multiple related tables.
3. Understand relationships between database tables.
4. Apply SQL joins to solve real-world database problems.

## Assignment Questions and Solutions

### Question 1: INNER JOIN – Employees and Offices

Retrieves employee information, including first name, last name, email, and office code by combining the `employees` and `offices` tables.

**Tables Used:**
- employees
- offices

**Join Type:** INNER JOIN

### Question 2: LEFT JOIN – Products and Product Lines

Retrieves product names, vendors, and product lines by combining the `products` and `productlines` tables.

**Tables Used:**
- products
- productlines

**Join Type:** LEFT JOIN

### Question 3: RIGHT JOIN – Customers and Orders

Retrieves order dates, shipped dates, order status, and customer numbers by combining the `customers` and `orders` tables. The query returns the first 10 records.

**Tables Used:**
- customers
- orders

**Join Type:** RIGHT JOIN
